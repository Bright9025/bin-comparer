# 🔍 bin-comparer

一款轻量级的二进制文件比较工具，提供图形化界面，可逐位分析两个文件的差异，并生成直观的 HTML 报告。

</div>

## ✨ 功能特点

- 🖱️ **图形化操作** – 基于 `tkinter`，通过弹窗选择两个二进制文件，无需命令行。
- 📊 **差异统计** – 精确统计总不同位数（包括文件长度不等时多余的全部位）。
- 🔴 **高亮显示** – 以第一个文件为基准，在 HTML 中用红色标记所有不同的位，黑色标记相同位。
- 🚀 **两种视图模式**：
  - **详细模式** – 显示全部字节，便于全面审查。
  - **精简模式** – 自动隐藏完全相同的行（8 个字节均无差异），快速定位差异区域。
- ⚡ **性能优化** – 借助 CSS `content-visibility` 实现按需渲染，即使超大文件（数十万行）也能流畅切换模式。
- 📁 **便捷导出** – 一键保存为 HTML 文件，并询问是否立即用浏览器打开。

## 🚀 如何使用

### 环境要求

- Python 3.6 或更高版本
- 标准库依赖（无需额外安装）：
  - `tkinter`（通常随 Python 自带）
  - `webbrowser`
  - `os`

### 1. 运行程序

在终端中执行：

```bash
python bin_comparer.py
```

### 2. 选择文件

- 程序弹出第一个文件选择对话框，选择您的第一个二进制文件（作为基准）。
- 接着弹出第二个文件选择对话框，选择待比较的第二个文件。

### 3. 保存报告

- 比较完成后，弹出“保存 HTML 报告”对话框，指定保存路径和文件名（默认扩展名 `.html`）。
- 保存成功后，程序询问是否立即用默认浏览器打开，点击“是”即可查看。

### 4. 交互查看

- 在 HTML 页面顶部显示两个文件路径、总不同位数。
- 每行显示 8 个字节，字节内 8 个二进制位（高位 → 低位），偏移量（蓝色）位于行首。
- 点击 **“切换模式”** 按钮，可在详细模式与精简模式间切换，切换时文字立即响应，界面流畅无卡顿。

## 📄 报告示例（局部）

```
0x0000  10101010 11110000 00001111 11111111 00000000 01010101 10101010 01010101
0x0008  11001100 00110011 10101010 01010101  ....................   (红色位表示差异)
```

- 所有红色位表示该位与第二个文件不同，黑色位表示相同。
- 精简模式下，完全无红色的行会被隐藏，帮助聚焦差异。

## 🎨 自定义与扩展

- **修改每行显示的字节数**：在 `generate_html_report` 函数中找到 `bytes_per_row = 8`，修改该值即可（建议保持为 8 的倍数以获得整齐对齐）。
- **调整字体大小**：在 HTML 模板的 `<style>` 中修改 `body` 或 `.byte-row` 的 `font-size` 属性。
- **更换偏移量颜色**：修改 `.offset` 中的 `color` 值（默认为 `#0066cc`）。
- **添加更多比较功能**：可基于 `compare_files` 函数扩展，例如输出差异统计图表等。

## 🌐 浏览器兼容性

生成的 HTML 报告支持所有现代浏览器（Chrome、Firefox、Safari、Edge），且利用 `content-visibility` 优化性能，推荐使用 Chrome 85+ 或 Firefox 109+ 获得最佳体验。

## 🧠 技术亮点

- **按位比较** – 逐字节对比，利用异或运算生成差异掩码，高效统计。
- **HTML 渲染优化** – 使用 `content-visibility: auto` 和 `contain-intrinsic-size`，仅渲染视口内的行，切换模式时仅重新计算可见区域的样式，大幅减少重排时间。
- **即时反馈** – 点击按钮后立即更新模式标签，再异步执行样式切换，让操作感受更灵敏。

## ⚠️ 局限性

- 程序一次性将两个文件全部读入内存，对于超大文件（>500MB）可能导致内存不足，建议用于常规大小的文件（如固件、日志、小型数据库等）。
- 输出 HTML 若差异极多，生成的文件体积可能较大，但现代浏览器均可正常打开。
